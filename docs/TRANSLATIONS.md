# Translation and Language Contributions

The project README advertises support for multiple languages. This guide sets expectations for translation contributions; it does not certify the completeness or quality of every translation currently in the app.

## Contribution principles

- Preserve the meaning and intent of the original text.
- Use natural language rather than literal word-for-word translation.
- Keep product names, URLs, placeholders, and formatting tokens intact.
- Respect right-to-left layout requirements for languages that use RTL scripts.
- Avoid adding text that promises features unavailable in the app.
- Keep terminology consistent across screens.

## Review checklist

- Check plural forms, punctuation, capitalization, and diacritics.
- Verify that placeholders and format arguments remain unchanged.
- Check that longer translations do not clip or overlap controls.
- Review the translated UI on a device or emulator when possible.
- Ask a fluent speaker to review substantial language changes when practical.

## Reporting a translation issue

Open an issue with the language, affected screen or string, current wording, and suggested correction. Do not include private user content in screenshots.

Follow [CONTRIBUTING.md](../CONTRIBUTING.md) before submitting translation changes.
