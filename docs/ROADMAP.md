# Project Roadmap Ideas

This file is an idea backlog for discussion, not a promise, schedule, or commitment that any item will ship.

## Repository and maintenance

- [ ] Add a reliable Android build workflow after validating SDK and signing requirements.
- [ ] Add dependency update automation and review its generated pull requests.
- [ ] Review repository security settings and branch rules.
- [ ] Establish a repeatable release checklist and artifact verification process.
- [ ] Add a third-party dependency license inventory for each release.

## Quality and usability ideas

- [ ] Review accessibility and large-font behavior across key screens.
- [ ] Expand automated tests around QR generation and scanning workflows.
- [ ] Review localization completeness and RTL layout.
- [ ] Document offline and network-dependent behavior based on verified implementation.

## Planning

Prioritize proposals based on user impact, maintenance cost, security, and available review capacity. Discuss significant changes in an issue before implementation.

To propose an item, open a [Feature Request](https://github.com/Dragons-Fox0058/qr-code-studio/issues/new/choose) with the problem it solves and a clear acceptance criterion.
