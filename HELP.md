# Help and User Guide

This guide explains where to find help for QR Code Studio and how to report a problem.

## Getting started

1. Install the latest APK from [GitHub Releases](https://github.com/Dragons-Fox0058/qr-code-studio/releases).
2. Confirm that your Android device runs Android 7.0 (API 24) or newer.
3. Open the app and grant a permission only when you use a feature that needs it.

For installation details, see [INSTALL.md](INSTALL.md).

## What the project documents

The project README describes QR creation, camera and gallery scanning, scan history, themes, language options, export formats, and other advertised capabilities. The exact options can vary by app release.

## Get help

- Read the [Frequently Asked Questions](docs/FAQ.md).
- Check [Troubleshooting](docs/TROUBLESHOOTING.md) for common installation and build problems.
- Search [existing GitHub issues](https://github.com/Dragons-Fox0058/qr-code-studio/issues) before opening a new one.
- Use the repository's Bug Report or Feature Request issue template when appropriate.
- For a security vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## When reporting a problem

Please include:

- App version and installation source.
- Android version and device model, if relevant.
- Clear steps to reproduce the problem.
- What you expected and what happened instead.
- A screenshot or a short, redacted log when it helps.

Do not attach passwords, API keys, signing files, private QR contents, personal information, or other secrets.
