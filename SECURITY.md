# Security Policy

## Supported Versions

Security fixes are prioritized for the latest published release. Older releases may not receive security updates.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | Best effort |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Use GitHub's **Report a vulnerability** feature on this repository's Security tab when private vulnerability reporting is available.

If that feature is unavailable, contact the maintainer through:

https://github.com/Dragons-Fox0058

Include, where possible:

- A clear description of the vulnerability.
- The affected version, branch, or commit.
- Reproduction steps or a proof of concept that does not expose real user data.
- The potential impact and any suggested mitigation.

Please allow the maintainer reasonable time to investigate and prepare a fix before publicly disclosing the issue. Do not include passwords, access tokens, private keys, or personal data in a report.
