# Support

## Questions and usage help

- Read the project documentation in this repository.
- Search existing [GitHub Issues](https://github.com/Dragons-Fox0058/qr-code-studio/issues) before opening a new one.
- If your question is not a bug report or feature request, use GitHub Discussions if it is enabled for this repository.

## Bug reports

Use the Bug Report issue template. Include the affected release, device/OS context when relevant, steps to reproduce, and expected versus actual behavior.

## Feature requests

Use the Feature Request issue template. Explain the problem the proposal would solve and why it would benefit the project.

## Security concerns

Do not post security vulnerabilities publicly. Follow the instructions in [SECURITY.md](SECURITY.md).
